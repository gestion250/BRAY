# 🤖 BRAY — Installation depuis GitHub

## Étape 1 : Télécharger BRAY

1. Ouvre le dépôt GitHub de BRAY.
2. Clique sur le bouton vert **Code**.
3. Clique sur **Download ZIP**.
4. Attends le téléchargement.
5. Extrais le fichier ZIP.

## Étape 2 : Installer BRAY sur Google Chrome

1. Ouvre Google Chrome.
2. Écris `chrome://extensions` dans la barre d'adresse.
3. Active **Mode développeur**.
4. Clique sur **Charger l'extension non empaquetée**.
5. Sélectionne le dossier BRAY extrait, celui qui contient `manifest.json`.
6. BRAY apparaît dans tes extensions !

## Étape 3 : Démarrer l'IA

1. Ouvre le dossier BRAY.
2. Clique dans la barre d'adresse.
3. Écris `powershell` et appuie sur Entrée.
4. Lance :

```powershell
.\start-ai-server.ps1
```

5. Confirme l'exécution si Windows le demande.
6. Laisse le terminal ouvert.

## Étape 4 : Utiliser BRAY

Clique sur l'icône BRAY dans Chrome et commence à discuter avec ton assistant IA.

## Besoin d'aide ?

Vérifie que le serveur IA est démarré et que ton ordinateur dispose des ressources nécessaires.
